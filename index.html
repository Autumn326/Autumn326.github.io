About me

I'm Michael, a Computer Science graduate who likes turning an idea into something that really works on a phone or a laptop.

I graduated with a First Class Honours BCS Computer Science degree. Along the way I studied software development, algorithms, databases, AI, data science, mobile development and cyber security, and I have tried to build something real in most of them.

My final year project, Sign Finder, is the one that shows best how I work. It is an iPhone app that recognises UK road signs from a photo or the live camera, entirely on the device so no image ever leaves the phone. I built the dataset myself from public sets plus my own annotated photos, compared several models, and learned to check the deployment path before committing to a training framework.

I like to design before I code. For the shopping manager I drew the use case and class diagrams first, for the theatre booking system I put the rules in one class and wrote tests that read like sentences, and for the Sudoku solver I let simple logic do most of the work and only guess when it has to. In the machine learning projects I judge a model with several measures and say plainly what the plots show, including where it gets things wrong.

I also like going back to my own work. My first Python program was one long script, and I have rebuilt that kind of code since with small functions and tests. The theatre system started life in Java and now lives in C++. Next on my list are a more balanced sign dataset, an LSTM for the sentiment model, and a puzzle generator for the Sudoku solver.
